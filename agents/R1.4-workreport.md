## 8. Appendix A — Implementation Takeover Qualification

### A1 Production Trace
In AVEVA PSI116 XML schemas, a reducer component typically defines two endpoints: Endpoint 1 (inlet) and Endpoint 2 (outlet). The taper angle `AlphaAngle` is assigned to Endpoint 2. In topological traversal order, the upstream approach pipe (e.g. `ELBO 530 -> REDU 540`) arrives first. In the baseline code, `_build_component_indices()` checked `(edge.to_node, edge.from_node)` for `REDU`. Because `540` was the reducer's inlet node, the approach pipe matched `REDU` and greedily claimed the reducer occurrence. When the actual reducer edge `(540 -> 550)` was reached, its occurrence had already been claimed and was discarded. Later, during payload generation, `_build_reducer_payload()` inspected the approach edge's owner node (`540`), where `AlphaAngle` was `None`, raising `ValueError: REDUCERS auxiliary edge has no PSI116 reducer component owner/AlphaAngle.`.

### A2 Current Failure Isolation
The defect is isolated strictly to reducer selection in `_build_reducer_indices()`. Bends and SIFs do not share endpoint angle semantics with reducers. The fix uncouples `_build_reducer_indices()` from the shared `_build_component_indices()` function, leaving bend and SIF logic untouched.

### A3 Authority / Invariant
- **Invariant 1:** No fabricated angles. If neither node nor occurrence record provides a valid non-zero `AlphaAngle`, the converter must fail closed (`ValueError`).
- **Invariant 2:** Multi-evidence ranking. Edge qualification requires endpoint occurrence co-identity (internal component edge connecting Endpoint 1 and Endpoint 2) as Rank 3/2, transition boundary as Rank 1, and approach edges as Rank 0 (rejected). Angle presence alone is not sufficient without topological grounding.
- **Invariant 3:** Non-reducer output must be byte-identical to baseline.

### A4 Independent Validation
- Verified with 6 unit tests in `test_reducer_internal_edge.py` failing on baseline and passing on patch.
- Verified on real GLRD production XML + staged JSON, emitting all 9 reducers with correct internal edge associations and unassociating approach edges.
- Verified byte-parity on two non-reducer benchmarks (`LAUNCHERTOPO.XML` and `RMS-BLOW-1.xml`).

### A5 Bounded Patch
The patch is bounded strictly to `xml_to_cii2019_contracted_direction.py`, adding 75 lines across 3 helper functions (`_reducer_taper_angle`, `_reducer_owner_node`, `_build_reducer_indices`). No changes to JS weight propagation, no RIGID mass allocation, and no merge to `main`.
